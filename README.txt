HOW TO RUN (Windows)
1. Extract the zip. Open the folder where run_lab.bat is located.
2. In VS Code terminal (PowerShell) in THIS folder type:   cmd /c run_lab.bat

3. After each step make a screenshot and press any key.
4. Open my-commit-repo\index.html in the browser (site in Kazakh).
