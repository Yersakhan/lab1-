Әр өзгеріс — бір коммит

Git тарихы осылай құралады: файл қосамыз, түсінікті хабарлама жазамыз, нәтижесін сақтаймыз.

Командаларды көру
  1. HEADUpdated index.html with thank you message--amend арқылы түзетілген соңғы коммит
  2. Add basic index.html fileБасты бет қосылды
  3. Initial commit with READMEЖоба басталды

Негізгі командалар

git add <файл>
Файлды индекске қосады, яғни келесі коммитке дайындайды.
git commit -m "хабарлама"
Индекстегі өзгерістерді коммит ретінде сақтайды.
git commit --amend
Соңғы коммитті өзгертеді: жаңа файл не жаңа хабарлама қосуға болады.
git log --oneline
Коммит тарихын қысқаша, бір жолмен көрсетеді.
git show <hash>
Нақты коммитте не өзгергенін көрсетеді.
git reset HEAD^
Соңғы коммитті болдырмайды, бірақ файлдарды қалдырады.
git checkout HEAD^ <файл>
Файлды алдыңғы коммиттегі күйінде қайтарады.
Git коммиттерімен жұмыс — зертханалық жұмыс
